Free GitHub Pages Hosting

  • Push this repository structure to your GitHub account.
  • Go to Settings > Pages in your GitHub repository.
  • Under Build and deployment > Source, choose Deploy from a branch.
  • Select branch main and directory / (root), then click Save.
  • Your master portal and all guides will be live at https://<username>.github.io/<repo>/!

Zero-Dependency Portability

Built in 100% pure HTML5, CSS3, and vanilla JavaScript with zero external frameworks, dependencies, or cloud fonts. Engineered for rapid offline execution and seamless static web hosting on GitHub Pages.

All progress checkmarks and states are persisted using a hardened in-memory fallback wrapper around localStorage, fully compatible with sandboxed mobile viewers, Android content:// URIs, and desktop file systems.
